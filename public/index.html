FAQ & Help Center TataDana

Pusat bantuan, panduan lengkap, dan jawaban pertanyaan umum

❓ Apa itu TataDana dan bagaimana cara kerjanya? ▼

TataDana adalah platform manajemen keuangan pribadi modern yang terintegrasi langsung dengan Telegram Bot dan Web App. Anda cukup mengirim pesan natural sehari-hari, rekaman suara (Voice Note), atau foto struk belanja ke bot Telegram.

Semua data transaksi otomatis tersimpan 100% secara real-time ke database Supabase dan langsung tampil di Dashboard Web Anda tanpa perlu input manual berulang.

🔒 Apakah data keuangan saya aman dan terisolasi dari akun lain? ▼

Sangat aman. TataDana menggunakan Row Level Security (RLS) PostgreSQL pada Supabase dan enkripsi token. Data setiap akun terisolasi penuh: saat Anda membuat akun baru, data Anda bersih dimulai dari saldo Rp 0, 0 pemasukan, dan 0 pengeluaran.

💬 Bagaimana cara menghubungkan akun TataDana dengan Telegram Bot? ▼

1. Buka menu Pengaturan > Tab Telegram di Dashboard TataDana.
2. Klik tombol "Hubungkan Telegram" untuk melihat kode tautan (contoh: LINK-8849).
3. Buka Telegram dan kirim perintah /start LINK-8849 ke bot kami. Status koneksi akan seketika berubah menjadi 🟢 Terhubung.

🤖 Kalimat dan perintah apa saja yang bisa dipahami oleh bot? ▼

AI TataDana mengenali format bahasa santai Indonesia:
• "beli bakso 15rb" (Otomatis pengeluaran Rp 15.000 ke kategori Makanan)
• "kopi 28k pakai gopay" (Pengeluaran dompet GoPay)
• "gajian 6jt masuk bca" (Pemasukan Rp 6.000.000 ke BCA)
• "transfer 100rb dari bca ke gopay" (Mutasi antar dompet)
• Perintah cepat: /saldo, /jatah, /budget, /hari ini, /minggu ini, /bulan ini, /rekap, /bantuan.
• Anda juga bisa kirim Voice Note atau Foto Struk Belanja (AI OCR Vision multi-item).

🎯 Bagaimana cara kerja fitur signature "TataJatah"? ▼

TataJatah menghitung Jatah Harian Aman Anda setiap hari secara dinamis berdasarkan zona waktu WIB:
Jatah Harian = (Saldo Dompet - Tagihan Wajib Belum Bayar - Target Tabungan) ÷ Sisa Hari ke Gajian Jika pengeluaran hari ini masih di bawah batas jatah harian, status Anda 🟢 Aman dan Streak kedisiplinan 🔥 Anda bertambah.

⚠️ Apa yang terjadi jika pengeluaran saya melebihi jatah harian? ▼

Status akan berubah menjadi 🔴 Lewat Jatah. Algoritma TataJatah akan otomatis membagi sisa saldo tersisa ke hari-hari berikutnya, sehingga batas jatah harian hari berikutnya disesuaikan agar Anda tetap bertahan tanpa defisit sampai hari gajian.

User Guide TataDana

Panduan lengkap mengelola keuangan semudah kirim chat Telegram

1

Menghubungkan Bot Telegram ke Akun TataDana

• Buka menu Pengaturan di dashboard, lalu pilih tab Bot Telegram.
• Klik tombol "Hubungkan Telegram" untuk mendapatkan kode unik (misal: /start LINK-8849).
• Buka Telegram dan kirim pesan kode tersebut ke @TataDanaBot. Status koneksi akan langsung berubah menjadi 🟢 Terhubung secara realtime!

2

Mencatat Pengeluaran & Pemasukan Sehari-hari

Ketik kalimat sehari-hari tanpa perlu membuka form rumit:
• Pengeluaran: beli bakso 15rb, kopi 28k pakai gopay, bensin 30ribu tunai.
• Pemasukan: gajian 6jt masuk bca, bonus freelance 1.5jt, terima uang 200rb.
• Voice Note (VN): Kirim rekaman suara saat di jalan, AI akan mentranskripsikannya otomatis.
• Foto Struk (Pro): Foto struk belanjaanmu (Indomaret, Alfamart, dll), AI Vision akan membaca tiap baris belanjaan secara terperinci.

3

Memilih & Memindahkan Dompet (BCA, GoPay, Tunai, Mandiri)

• Sebutkan nama dompet di dalam pesan (misal: "pakai gopay" atau "masuk bca").
• Jika lupa menyebut dompet, bot akan memakai dompet default dan memberikan tombol [🔄 Ganti Dompet] yang bisa Anda klik untuk memindahkan mutasi.
• Untuk transfer antar dompet: ketik transfer 200rb dari bca ke gopay.

4

Fitur Signature "TataJatah" (Jatah Harian Aman)

• TataDana menjawab pertanyaan: "Hari ini aku boleh jajan berapa supaya gajiku cukup sampai akhir bulan?"
• Ketik /jatah di bot untuk melihat jatah harianmu hari ini.
• Gunakan fitur simulasi "Kalau Aku Beli Ini?" di dashboard sebelum membeli barang impian agar keuangan tetap aman.
